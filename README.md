# 🎮 GT-Engine (2.5D C# Minimalist Pixel Engine Runner)

یک موتور بازی سبک، سریع و داده‌محور به زبان **#C** بدون محیط ادیتور گرافیکی، طراحی‌شده اختصاصی برای اجرای بازی‌های **۲.۵ بعدی پیکسلی** با کارایی فوق‌العاده روی سخت‌افزارهای قدیمی (مانند کارت گرافیک **NVIDIA GT 630**).

---

## 🚀 ویژگی‌های کلیدی موتور

1. **بدون ادیتور (Pure Engine Runner):**
   - موتور فاقد هرگونه ابزار ویرایشی یا رابط کاربری سنگین است.
   - تنها مسئولیت موتور دریافت مسیر پوشه بازی (`./game`)، خواندن دارایی‌ها و اجرای بازی است.

2. **بهینه‌سازی حداکثری برای کارت‌های قدیمی (GT 630 Friendly):**
   - **Virtual Framebuffer Rendering:** رندرینگ تمام صحنه روی یک بوم با رزولوشن پایین (مثلاً $320 \times 180$ یا $640 \times 360$) و بزرگنمایی Pixel-Perfect با فیلتر Point/Nearest-Neighbor.
   - **Zero-Allocation Memory Architecture:** استفاده از `struct`ها، حافظه استاتیک و Object Pooling برای به حداقل رساندن کارهای Garbage Collection و جلوگیری از Stuttering.
   - **Fast AABB Physics:** سیستم برخورد جعبه‌ای ۲.۵ بعدی بسیار سریع بدون بار اضافی روی CPU.

3. **سیستم به‌روزرسانی لایه‌ای و آپدیت‌های اپیزودیک (Virtual File System & Patching):**
   - پشتیبانی از **Layered VFS**؛ موتور به محض اجرا پوشه‌ی `game/patches/` را اسکن می‌کند.
   - برای انتشار آپدیت جدید کافیست فایل‌های تغییر یافته در یک پوشه پچ قرار گیرند؛ موتور به‌صورت هوشمند فایل‌های جدید را جایگزین نسخه‌های قبلی در حافظه می‌کند.

4. **امنیت و انتشار بسته (Closed Source Production Ready):**
   - پشتیبانی از **.NET Native AOT Compilation** جهت تبدیل کدهای C# به فایل باینری کاملاً نیتیو بدون قابلیت بازگردانی سورس‌کد.
   - قابلیت بسته‌بندی و رمزنگاری Assetها در نسخه نهایی انتشار برای جلوگیری از دستکاری کاربران.

## 📁 ساختار پروژه

```text
├── Engine.csproj               # فایل تنظیمات پروژه‌ی C# (.NET 8.0 با Native AOT)
├── Program.cs                  # نقطه ورود اصلی (CLI Runner)
├── src/                        # کدهای اصلی موتور
│   ├── Core/
│   │   ├── GameRunner.cs       # حلقه اصلی اجرای بازی (Game Loop)
│   │   ├── Time.cs             # سیستم محاسبه زمان و FPS
│   │   └── VFS.cs              # سیستم فایل مجازی لایه‌ای (پشتیبانی از پچ‌ها)
│   ├── Graphics/
│   │   ├── PixelCanvas.cs      # بوم رزولوشن پایین برای رندر پیکسلی
│   │   ├── SpriteBatch.cs      # رندرکننده صفر-تخصیص اسپریت‌ها و لایه‌ها
│   │   ├── Camera2D.cs         # دوربین ۲.۵ بعدی با شیک و تعقیب نرم
│   │   └── Color.cs            # ساختار رنگ پیکسلی
│   ├── Physics/
│   │   ├── AABB.cs             # برخورد ۲.۵ بعدی متقاطع
│   │   └── PhysicsSystem.cs    # سیستم فیزیک محیطی
│   ├── Logic/
│   │   ├── Entity.cs           # موجودیت‌های بازی با اولویت عمق Z
│   │   ├── IGameLogic.cs       # اینترفیس اصلی منطق بازی
│   │   └── ScriptLoader.cs     # لودکننده داینامیک کدهای بازی
│   ├── Audio/
│   │   └── AudioSystem.cs      # سیستم استریم صدا و افکت‌ها
│   └── Data/
│       ├── SaveSystem.cs       # سیستم ذخیره‌سازی وضعیت بازی
│       └── PatchInstaller.cs   # نصب‌کننده هوشمند پچ‌های به‌روزرسانی
└── game/                       # پوشه‌ی بازی (کنار فایل اجراکننده موتور)
    ├── config.json             # تنظیمات گرافیکی و فریم بازی
    ├── README.md               # راهنمای پوشه بازی
    ├── assets/                 # تصاویر، صداها و نقشه‌ها
    └── patches/                # پچ‌های بروزرسانی (patch_v1.1, patch_v1.2)
```

## 🛠 نحوه اجرا و استفاده

### اجرا از طریق خط فرمان (CLI):
```bash
# اجرای موتور و بارگذاری پوشه پیش‌فرض ./game
dotnet run

# یا دادن مسیر سفارشی به پوشه بازی
dotnet run -- ./path-to-custom-game-folder
```

### خروجی خروجی نهایی نیتیو (Native AOT Build for Release):
```bash
dotnet publish -c Release -r win-x64 --self-contained
```
خروجی این دستور یک فایل اجراکننده `.exe` نیتیو است که نیاز به هیچ نصب پیش‌نیازی ندارد و فایل‌های سورس کد C# در آن کاملاً محافظت شده است.

## جریان لودینگ فعلی

`LoadingScreen` جریان کیبوردی زیر را تعریف می‌کند: تصویر `game/assets/ui/image.png` هنگام لود نمایش داده می‌شود، پس از تکمیل روشن‌تر می‌شود و با اولین کلید/کلیک صدای `menu_confirm` پخش شده و منوی `PLAY / OPTIONS / EXIT` ظاهر می‌شود. مکان‌نما باید توسط backend پنجره مخفی بماند. `PLAY` فعلاً عمداً غیرفعال است و `OPTIONS` شامل تنظیمات صدای اصلی، موسیقی و افکت و گزینه‌ی برگشت است.

پس از همان کلیک، موسیقی `game/assets/audio/untrust.ogg` (یا `.wav`) شروع می‌شود و پس‌زمینه‌ی منو از `game/assets/ui/negri.png` خوانده می‌شود. فایل‌های تصویری پیوست‌شده را باید با همین نام‌ها در این مسیرها کپی کرد.

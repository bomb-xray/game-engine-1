# محل فایل‌های لودینگ

فایل‌ها را اینجا قرار دهید:

- `game/assets/ui/image.png` — تصویر اول لودینگ
- `game/assets/ui/negri.png` — پس‌زمینه‌ی منوی اصلی (نام فایل دقیقاً همین باشد)
- `game/assets/audio/untrust.ogg` یا `game/assets/audio/untrust.wav` — موسیقی، بعد از کلیک اول پخش می‌شود
- `game/assets/audio/menu_confirm.wav` — صدای تأیید کلیک/انتخاب

اگر فایل موسیقی MP3 است فعلاً همان را قرار دهید، اما برای لود سریع و پخش کم‌مصرف روی سیستم ضعیف، تبدیل به OGG یا WAV توصیه می‌شود. موتور در نسخه‌ی فعلی فقط مسیر Asset و رویداد پخش را آماده می‌کند؛ backend پنجره، تصویر و صدای واقعی باید با SDL2/Raylib به آن متصل شود.

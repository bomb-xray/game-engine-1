# Game Project Folder

این پوشه، تمام دارایی‌ها و کدهای بازی را در خود جای داده است.

## ساختار پوشه‌ها:
- `config.json`: تنظیمات اصلی رزولوشن، VSync و هدف فریم بازی.
- `assets/`: تصاویر، کاشی‌ها (Tilemaps)، انیمیشن‌ها و صداها.
  - `sprites/`: تصاویر پیکسلی و اسپریت‌شیت‌ها.
  - `audio/`: موسیق‌های پس‌زمینه و افکت‌های صوتی.
  - `levels/`: فایل‌های طراحی مرحله.
- `patches/`: پوشه‌ی بسته‌های به‌روزرسانی (مثلاً `patch_v1.1/` یا `episode2/`). سیستم لایه‌ای VFS موتور به‌صورت خودکار هر فایلی در پچ‌ها باشد را جایگزین فایل‌های اصلی می‌کند.
- `Game.dll`: خروجی کامپایل کدهای بازی که توسط موتور لود می‌شود.
